---
title: "Strix v2 Validation"
description: "Validation contract for the terminal and read-only viewer"
---

Strix v2 uses protocol version 8. Pydantic command/result models generate the JSON Schema and Go structs; CI rejects generation drift.

Run `make check-all` to execute Ruff check and format-check, mypy, Bandit, pytest, protocol generation checks, `gofmt`, `go vet`, Go race tests, and frontend type-check/test/build. Use `make format` separately when applying formatting changes.

Launch the source checkout with `uv run strix`. The browser opens only through `/viewer` and exposes no mutation controls or endpoints.
