Strix coordinates autonomous security agents inside a Docker sandbox and reports validated findings with evidence. Version 2 replaces CLI configuration and headless execution with one typed terminal TUI.

## Start

```bash
curl -sSL https://strix.ai/install | bash
strix
```

Use `/connect`, `/models`, `/targets`, `/settings`, `/router`, and `/start`. The browser viewer is read-only, environment credentials are detection hints only, and removed v1 flags fail before a run begins.

## Why the v2 boundary matters

- One `AppConfig v3` owns provider connections, router policy, scan defaults, MCP, notifications, and UI preferences.
- Provider adapters declare their own authentication and model discovery contract.
- The router chooses per logical task using capability, quality, reliability, cost, and latency metadata.
- Recovery is bounded to three distinct routes and never replays after output or a side effect.
- Protocol v8 keeps Python and Go command/result types generated from one schema.
