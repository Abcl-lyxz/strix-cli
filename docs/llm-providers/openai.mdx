---
title: "OpenAI"
description: "Connect OpenAI through the provider-native TUI adapter"
---

Run `/connect`, choose **OpenAI**, and enter the API key. Then use `/models` to discover and enable models. The official endpoint is supplied by the adapter and no Base URL is requested.

An `OPENAI_API_KEY` environment value may be detected as a connection source, but it never overrides a TUI-selected connection.
