---
title: "Local Models"
description: "Connect local runtimes through explicit adapters"
---

For Ollama, run `/connect` and choose **Ollama**. The adapter detects the local runtime and `/models` discovers its models. For another OpenAI-compatible local runtime, use **Custom OpenAI-compatible** and provide its local Base URL.

Unknown local endpoints are not inferred from environment variables or model-name prefixes. Tool support, context, and modalities must be verified before a model becomes router-eligible.
