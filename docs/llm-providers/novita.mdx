---
title: "Other Hosted Providers"
description: "Use an explicit plugin or Custom OpenAI-compatible adapter"
---

If a hosted provider has a ProviderAdapter v2 plugin, install it and connect through `/connect`. If the service intentionally implements the OpenAI API contract, choose **Custom OpenAI-compatible**, enter its Base URL and optional key, then use `/models`.

Providers are never promoted from catalog metadata into a generic form automatically.
