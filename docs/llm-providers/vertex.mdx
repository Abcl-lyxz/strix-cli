---
title: "Google Vertex AI"
description: "Vertex AI requires a ProviderAdapter v2 plugin"
---

Vertex AI uses project, region, and cloud credential-chain semantics that cannot be represented by a generic API-key form. Install a trusted plugin that registers a `strix.providers` adapter with `api_version = 2`; it will then appear in `/connect` with its own fields and model discovery.

Strix never downloads executable provider plugins from the remote model registry.
