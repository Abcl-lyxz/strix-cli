---
title: "Doctor"
description: "Diagnose the local Strix installation"
---

Run the only diagnostic utility available outside the TUI:

```bash
strix doctor
```

Doctor checks the local installation and Docker prerequisites without starting a scan. Provider-specific connection diagnostics are also available from `/doctor` and `/connect` inside the TUI, where the selected AppConfig v3 connection is explicit.

If a provider or network check fails, verify Docker, proxy/VPN routing, the adapter's credential source, and the provider's native endpoint. Do not work around a failed connection by passing removed v1 flags; they intentionally fail before scan setup.
