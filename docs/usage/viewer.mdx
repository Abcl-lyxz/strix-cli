---
title: "Read-only Viewer"
description: "Observe live and saved runs without a second control plane"
---

Open the viewer from the TUI with `/viewer`.

The browser exposes live transcript, agent graph, findings, artifacts, reports, and compatible saved runs. It uses GET, SSE, and download endpoints only. Provider configuration, command dispatch, uploads, scan setup, and agent steering are intentionally unavailable; mutation requests return `404` or `405` after authentication.

The viewer binds locally and uses a tokened URL. Treat that URL as access to local scan evidence. Legacy runs remain viewable, but only v2 run schemas can resume in the TUI.
