## Entry points

```bash
strix
strix --help
strix --version
strix doctor
```

`strix` opens the TUI. Scan/setup flags and v1 subcommands are not accepted. If a removed flag is present, Strix exits before creating or resuming a run so a partial configuration can never start accidentally.

## Canonical commands

| Command | Purpose |
|---|---|
| `/connect` | Add, rotate, inspect, or disconnect provider-native credentials |
| `/models` | Discover models, inspect capabilities, and enable router candidates |
| `/router` | Inspect policy, eligible models, health, decisions, and fallback history |
| `/settings` | Edit typed settings and see their true apply scope |
| `/targets` | Add, remove, list, or clear scan targets |
| `/attach` | Add supporting files or directories |
| `/mcp` | Configure MCP connections for the next scan |
| `/sessions` | Browse or resume compatible v2 runs |
| `/notifications` | Browse notifications and dispatch typed actions |
| `/update` | Run the verified updater and show progress/restart state |
| `/doctor` | Run installation and provider diagnostics |
| `/start` | Freeze the current draft into an immutable run configuration |
| `/status` | Show scan and router status |
| `/agents` | Focus or stop an agent |
| `/findings` | Browse validated findings |
| `/trace` | Open the live transcript |
| `/viewer` | Open the read-only browser viewer |
| `/find` | Search the local workspace without an LLM turn |
| `/editor` | Edit a multiline prompt in the configured editor |
| `/new` | Create a new scan draft |
| `/help` | Show the command registry |
| `/quit` | Exit Strix |

The palette and help modal are generated from this same registry. Removed commands including `/model`, `/apikey`, `/baseurl`, `/routes`, `/routing`, `/config`, and `/retry` produce a migration error.

## Settings apply scopes

Every setting declares one scope: `immediate`, `next_request`, `next_scan`, or `restart`. Starting a scan creates an immutable `RunConfig`; setup changes marked `next_scan` never rewrite a live run.

## Configuration ownership

`~/.strix/config.json` is the AppConfig v3 source of truth. Strix v2 does not migrate or overwrite v1 `cli-config.json`, legacy route files, or legacy keychain entries. Environment values may be detected as credential hints but cannot override TUI choices.
