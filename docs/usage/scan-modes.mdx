---
title: "Scan Defaults and Limits"
description: "Configure scan behavior through typed TUI settings"
---

Open `/settings` before starting a scan. The form owns scan depth, scope, budget, turn and agent limits, reasoning, caching, streaming, notification preferences, and recovery limits.

- `quick` prioritizes a bounded first pass.
- `standard` balances surface coverage and depth.
- `deep` allows broader exploration when time and model budget permit.

These modes are planning defaults, not completeness guarantees. Review the final coverage, run status, and cost before interpreting an empty findings list as clean. Settings marked `next_scan` are copied into the immutable run configuration only when `/start` is accepted.
