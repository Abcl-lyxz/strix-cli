## Prerequisites

- Docker running
- Python 3.12 or newer
- Credentials for a [supported provider](/llm-providers/overview)

## Install and open

```bash
curl -sSL https://strix.ai/install | bash
strix
```

Strix v2 opens the terminal TUI. It does not expose a headless scan command.

## Connect and scan

1. Open `/connect`, select a provider adapter, and complete its native credential fields. You do not need to pick a model at connection time.
2. Open `/models`, discover the models available to that connection, and enable the models the automatic router may use.
3. Add scope with `/targets add <url-or-path>` and supporting files with `/attach`.
4. Review limits and scan defaults in `/settings`.
5. Inspect eligible models in `/router`, then run `/start`.

Credentials detected from the environment are offered as connection sources; they never override TUI state silently. Base URL appears only for Custom OpenAI-compatible, proxy, or advanced adapters.

<Note>
The first scan may pull the Docker sandbox image. Results are saved under `strix_runs/<run-name>`.
</Note>

## Utilities

Outside the TUI, only these commands are supported:

```bash
strix --help
strix --version
strix doctor
```

Legacy v1 flags fail before a scan starts and explain which TUI command replaces them.
